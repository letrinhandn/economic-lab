# Solow–Swan

Quarto essay: `index.qmd`

## Bundle

Complete zip (`qmd` + figures + scripts + config):

```bash
make zip NAME=solow-swan-tang-truong
```

→ `bundles/solow-swan-tang-truong.zip`

## Figures

Regenerate model figures (matplotlib simulations matching essay params
$\alpha=0.35$, $s=0.24$, $n=0.015$, $g=0.02$, $\delta=0.05$):

```bash
make figures
# or:
uv run --python 3.12 python posts/solow-swan-tang-truong/scripts/generate_figures.py
```

Script: `scripts/generate_figures.py` → writes into `figures/`.

Not regenerated by the script (keep as-is):

- `hinh-1-1-dai-suy-thoai.png` — historical photo
- `thumbnail.jpg` / `thumbnail.png` — cover art

Tables (Bảng y/MPK, 3.1, 6.1) are Markdown in `index.qmd`, not PNGs.
